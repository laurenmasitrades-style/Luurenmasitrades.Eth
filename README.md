# Wallet Tool

A simple web app to derive Ethereum addresses from a mnemonic or private key, connect securely via MetaMask, and export balances to CSV. Includes QR code generation and optional encrypted local storage for mnemonics.

## ✨ Features
- Derive multiple addresses from a mnemonic/private key
- Show live ETH balances
- Display derivation paths
- Auto-download CSV with addresses, balances, and paths
- Connect MetaMask for secure wallet retrieval
- Generate QR codes for addresses
- Encrypt and store mnemonics locally with AES
